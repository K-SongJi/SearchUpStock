# 급등 후보 조건검색기

국장/미장 종목을 입력하면 기술적 조건을 정해진 순서대로 계산해서 급등 전 후보인지 보조 판단하는 프로그램입니다.

> 이 프로그램은 매수 추천이나 수익 보장을 의미하지 않습니다. 거래량, 뉴스, 시장 분위기, 손절 기준을 함께 확인해야 합니다.

## 분석 순서

1. 이동평균선: MA5, MA20, MA60, MA5/MA60 골든크로스, 이동평균 밀집
2. 볼린저밴드: 20일 중심선, 표준편차 2배, 밴드폭 축소, 상단 방향 이동
3. 거래량: 20일 평균 대비 현재 거래량, 가격 상승과 거래량 증가 동시 발생
4. RSI: 14일 기준, 50 돌파, 60~70 상승 힘, 70 이상 과열
5. 이격도: 종가 / MA20 * 100
6. 스토캐스틱 Slow: 14, 3, 3 기준 K/D 골든크로스와 데드크로스

## 점수

- 이동평균선: 20점
- 볼린저밴드: 20점
- 거래량: 20점
- RSI: 15점
- 이격도: 15점
- 스토캐스틱: 10점

총점 계산 후 거래량 필터를 적용해 최종 점수와 등급을 다시 계산합니다.

## 등급

- 80점 이상: 급등 후보 강함
- 65점 이상 80점 미만: 관심종목
- 50점 이상 65점 미만: 관망
- 50점 미만: 매수 부적합

## 설치

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 콘솔 실행

```powershell
.\.venv\Scripts\python.exe -m surge_analyzer.cli AAPL 005930 --period 1y
```

## 웹페이지 실행

```powershell
.\.venv\Scripts\python.exe -m surge_analyzer.web_app
```

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:5000
```

## 웹 기능

- 여러 종목 동시 입력
- 한국 종목명 입력 지원
  - 예: `삼성전자`, `두산에너빌리티`, `구영테크`
  - 6자리 종목 코드도 계속 지원합니다.
- 최종 점수 높은 순서로 정렬
- 조건검색 통과 종목 수 표시
- 데이터 부족 종목 표시
- 결과 표에서 한국 종목은 종목명을 우선 표시
- 종목별 상세 점수와 주의사항 표시
- 선택 종목 차트 표시
- DB 업로드 탭에서 검증 엑셀을 MySQL에 저장
- 검증 모드에서 DB 누적 데이터를 기준으로 성과 분석

차트에는 종가, MA5, MA20, MA60, 볼린저밴드, 거래량, RSI, 이격도, 스토캐스틱이 표시됩니다.

## MySQL 설정

```powershell
copy .env.example .env
```

`.env`에 MySQL 접속 정보를 입력한 뒤 스키마를 생성합니다.

```powershell
.\.venv\Scripts\python.exe -m surge_analyzer.db
```

기본 DB 이름은 `stock_analysis`입니다.
